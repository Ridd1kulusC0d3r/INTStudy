# Revisão de qualidade

Use **0 = ausente**, **1 = parcial**, **2 = explícito e sustentado**. Esta é uma rubrica pedagógica local, não padrão oficial nem certificação.

| Critério | Nota | Evidência / correção |
|---|---|---|
| Pergunta vinculada a uma decisão | | |
| Fontes rastreáveis e temporalidade correta | | |
| Independência das fontes examinada | | |
| Observação separada de inferência | | |
| Hipótese alternativa considerada | | |
| Confiança fundamentada e lacunas explícitas | | |
| Recomendação proporcional à evidência | | |
| Reprodução possível sem dados sensíveis | | |

**Regra de conclusão:** nenhum zero em fontes, separação observação/inferência ou confiança. O total não compensa a falta de evidência. Registre pendências; não invente uma correção apenas para cumprir a atividade.
